МОЙ ДЕНЬ — PWA-прототип

Состав: index.html, manifest.webmanifest, sw.js, иконки.

Для установки на iPhone:
1. Разместите содержимое папки на HTTPS-хостинге (например, GitHub Pages).
2. Откройте опубликованный HTTPS-адрес в Safari на iPhone.
3. Нажмите «Поделиться» → «На экран Домой» → «Добавить».

Данные задач сохраняются локально в браузере на этом устройстве.

Важно: это первая версия-прототип. Напоминания в заданное время и автоматический вечерний запуск пока не реализованы как системные уведомления. Для надёжных push-уведомлений PWA на iPhone потребуется HTTPS, серверная push-инфраструктура и настройка подписки. В этой версии перенос задач срабатывает при открытии приложения; вечерний обзор можно открыть вручную.
